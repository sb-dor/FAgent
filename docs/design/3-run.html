Одно приложение на проект: запуск привязан к проекту, а не к чату — все чаты проекта видят тот же запуск, агент управляет им через MCP (hot_reload, get_runtime_errors, скриншот). Кнопки ▶/⚡ в шапке окна — короткий путь к тому же запуску. Ошибки во время хода агента он видит сам; «→ Отправить агенту» — вручную в текущий чат.
