Скилл vs правило

Скилл — инструкция «как сделать X» (папка с SKILL.md, формат Anthropic Skills — работает и в обычном Claude Code). Агент подгружает его сам, когда задача подходит, или по «/имя».
Правило — best practice, которое действует всегда (архитектура, стиль, «проверяй версию пакета»). Короткий Markdown, уходит агенту в начале каждой сессии.

Источники и область

Встроенные (с приложением, только чтение) · Мои (в папке приложения) · Проект (.claude/skills в репо — общие с командой) · git-репозитории. Каждый скилл/правило включается глобально, с исключениями по проектам; чип 🧩 в чате меняет только этот чат.
