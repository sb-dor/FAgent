# Code View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-project **Chat | Code** switch above the chat column; Code is an explorer plus a re_editor-based editor with tabs, saving, find and disk sync.

**Architecture:** New feature `lib/src/feature/code_view/`. `ICodeFilesRepository` wraps the file system and `git`. Per project, a `CodeWorkspace` owns a `FileTreeController` and a `CodeTabsController`, and both share one watch stream. Each open file is a `CodeDocument` holding a re_editor `CodeLineEditingController`, kept separate from the `CodeEditorView` widget that shows it. `CodeViewRegistry` (in `Dependencies`) implements `common/unsaved_files/IUnsavedFiles` so that `app_close` and the chat can see unsaved files without importing the feature.

**Tech Stack:** Flutter macOS, re_editor 0.10.0 (re_highlight 0.0.3), control, freezed, drift (v10 → v11), gen-l10n en/ru.

**Spec:** `docs/superpowers/specs/2026-11-04-code-view-design.md` (Russian).

## Global Constraints

- Follow CLAUDE.md and `docs/AI_INSTRUCTIONS.md`.
  - `common/` never imports `feature/`.
  - Feature widgets take colors only from `context.colors` and radii from `AppRadius`.
  - Every `Stream`-returning repository method follows "Stream-Returning Methods"; every subscription is cancelled in `dispose`.
- Dependency: `re_editor: ^0.10.0`. Before adding it, check pub.dev. If `flutter pub get` fails because of `isolate_manager ^4.1.5`, report BLOCKED. Do not override dependencies.
- Hidden from the explorer and from watch: `.git` and `.dart_tool` at any depth; `build` when its parent folder holds `pubspec.yaml`.
- Limits: a file over 5 MB (`5 * 1024 * 1024` bytes) is too large. A file is not text if it has a NUL byte in its first 8192 bytes or isn't valid UTF-8.
- Watch events are merged over 100 ms. Explorer width: default 240, clamped to 180–480. State is saved 300 ms after the last change.
- Image extensions shown as pictures: `png`, `jpg`, `jpeg`, `gif`, `webp`.
- Copy: all of it comes from the spec, in en and ru arb files. Russian strings are verbatim from the spec, for example «Чат», «Код», «Файл изменён на диске», «Загрузить с диска», «Оставить мои», «Удалён», «Не открывается в редакторе», «Выберите файл слева или нажмите ⌘P», «N несохранённых файлов — агент видит версию с диска», «Сохранить все», «Отправить так».
- Shortcuts while the Code view is shown: ⌘S, ⌘W, ⌘P; ⌘F belongs to re_editor's find. The existing ⌘N ⌘K ⌘\ ⌘J ⌘R ⇧⌘R ⌘, keep working while the editor has focus.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Opening a file and saving it with no edits keeps its bytes identical: CRLF endings, no trailing newline, emoji and other non-ASCII text (Task 4).
2. Saving a symlinked file writes the link's target and leaves the link in place. An executable file (`gradlew`) keeps its mode after a save (Task 1).
3. When the agent rewrites an open file soon after the app saved it, the change is still noticed: the stamp compares modification time at full resolution plus size, so the app's own save is the only write it ignores (Task 4).
4. Esc while the find panel is open closes the panel only and does not leave the Code view. While the editor is focused, ⌘R still hot-reloads and ⌘K still opens chat search (Task 6).
5. Expanding a folder with thousands of entries keeps the UI responsive (list off the UI isolate, flat `ListView.builder`), and `flutter run` writing into `build/` sends no watch events (Tasks 1 and 3).

**Interfaces:**
- Produces:
  - Models in `code_file.dart`:
    - `FileNode({required String path, required String name, required bool isDirectory, bool ignored = false})`, where `path` is absolute;
    - `FileStamp({required DateTime modified, required int size})`, with value equality;
    - `FileContent({required String text, required FileStamp stamp})`;
    - `enum FileChangeKind { created, modified, deleted }` and `FileChange({required String path, required FileChangeKind kind})`.
  - Exceptions: `FileNotTextException(String path)`, `FileTooLargeException(String path, int size)`, `FileChangedOnDiskException(String path, FileStamp? actual)`, where `null` means the file is gone.
  - `abstract interface class ICodeFilesRepository`:
    - `Future<List<FileNode>> list(String root, String dir)`: folders first, then files, each sorted case-insensitively by name. Hidden entries are left out. `ignored` comes from `git -C root check-ignore --stdin` (the git binary from `ShellEnvironment.which('git')`, its variables, `includeParentEnvironment: false`, as `file_mention/data/project_files_repository.dart` does). No git or not a repository means nothing is ignored.
    - `Stream<FileChange> watch(String root)`: `Directory(root).watch(recursive: true)`, without the hidden folders, merged per path over 100 ms.
    - `Future<FileContent> read(String path)`: read in an isolate. Throws the exceptions above.
    - `Future<FileStamp?> stamp(String path)`: `null` when the file is missing.
    - `Future<FileStamp> write(String path, String text, {required FileStamp? expected})`. Resolve symlinks first. When `expected != null` and the current stamp differs, throw `FileChangedOnDiskException`. Write UTF-8 to a temp file in the same folder, copy the original mode (`chmod`, octal of `FileStat.mode & 0x1FF`) when the file existed, rename it over the original, and return the new stamp.
  - `final class CodeFilesRepositoryImpl implements ICodeFilesRepository` with constructor `CodeFilesRepositoryImpl({required ShellEnvironment environment})`.

    - fields: `String path`, `CodeDocumentKind kind`, `CodeLineEditingController editing`, `FileStamp? stamp`;

    - `void keepMine()` clears `changedOnDisk` and makes the next save overwrite without asking.

      - `Future<void> restore()` drops missing files silently;

      - `void activate(String path)`;
      - `bool close(String path, {bool discard = false})` returns `false` and keeps the tab when it's dirty and `discard` is false;
      - `void setMode(CodeViewMode mode)`;
      - `void setExplorerWidth(double width)` clamps to 180–480.
    - State is saved 300 ms after the last change, with paths relative to `root`.
    - Changes to open files:
      - `modified` with a stamp different from the document's: a clean document reloads, a dirty one gets `changedOnDisk`;
      - `deleted` sets `deleted`;
      - `created` for a deleted document clears `deleted` and reloads it if it's clean.
  - `final class CodeWorkspace`:
    - constructor `CodeWorkspace({required int projectId, required String root, required ICodeFilesRepository files, required ICodeViewStateRepository state})`;
    - it opens `files.watch(root).asBroadcastStream()` once and exposes `FileTreeController tree` and `CodeTabsController tabs`;
    - `dispose()`.
  - `final class CodeViewRegistry extends ChangeNotifier implements IUnsavedFiles`:
    - constructor `CodeViewRegistry({required ICodeFilesRepository files, required ICodeViewStateRepository state})`;
    - `CodeWorkspace workspaceFor({required int projectId, required String root})` is created lazily and kept;
    - it notifies when any document's `dirty` changes;
    - `dispose()`.
