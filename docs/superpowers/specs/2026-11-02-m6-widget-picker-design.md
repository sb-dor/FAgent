# M6: Визуальный выбор виджета

Веха M6 из `docs/PLAN.md`. Готово, когда: в запущенном в debug приложении «Выбрать виджет» на вкладке
Run включает режим выбора, касание виджета в приложении показывает в карточке его имя,
`файл:строка:столбец`, цепочку предков проекта и снимок самого виджета; «Добавить в сообщение» кладёт
в черновик открытого чата строку `@widget …`, цепочку и `@путь` снимка; клик по звену цепочки
переключает карточку на этот виджет.

## Цель и рамки

UI выбора уже есть (кнопка на вкладке Run, `PickedWidgetCard`, передача в черновик
`WorkspaceRunLink.addWidget`), но `IWidgetPickerRepository` — `FakeWidgetPickerRepositoryImpl`, который
всегда «выбирает» `BookingCard`. M6 ставит за тот же интерфейс настоящий репозиторий, который говорит с
инспектором виджетов запущенного приложения через его VM service.

Решения пользователя: «список» из PLAN.md — цепочка предков в карточке; в чат — текст и снимок только
виджета; один выбор, затем режим выключается; рефакторинг `agent_hub.dart` — отдельно до M6 (сделан,
PR #12).

Вне рамок: полное дерево виджетов (как в DevTools), переход к строке в редакторе (нужна интеграция с
редактором), выбор в profile/release (инспектора там нет), подсветка в самом приложении после выбора
(см. факты).

## Установленные факты (Flutter 3.47.1, `packages/flutter/lib/src/widgets/widget_inspector.dart`)

- `ext.flutter.inspector.show` (`enabled: 'true'|'false'`) включает и выключает режим выбора в
  приложении (`debugShowWidgetInspectorOverride`); выключение очищает выделение
  (`selection.currentElement = null`) и убирает рамку. Изменение публикуется событием
  `Flutter.ServiceExtensionStateChanged` (поток `Extension`).
- Выбор касанием (и `setSelectionById`) вызывает `_notifyToolsOfSelection`: событие `navigate`
  в потоке `ToolEvent` с `fileUri`, `line`, `column`, `source: 'flutter.inspector'`; при
  `restrictToProjectFiles` — ближайший виджет проекта.
- `getSelectedSummaryWidget(objectGroup)` — выбранный виджет дерева «summary» (виджеты проекта) с
  `description`, `valueId`, `creationLocation` (`file` — `file://` URI, `line`, `column`).
- `getParentChain(id, objectGroup)` — цепочка от корня до узла: `[{node, children, childIndex}]`, у
  `node` — `description`, `valueId`, `creationLocation`, `createdByLocalProject`.
- `screenshot(id, width, height, margin?, maxPixelRatio?)` — PNG в base64 (`null`, если не вышло);
  работает по id без режима выбора.
- `disposeGroup(objectGroup)` освобождает id группы. Всё это — только debug (и `--track-widget-creation`,
  по умолчанию в debug).
- Запуск уже знает адрес VM service и режим сборки: `RunRunning.vmServiceUri`, `RunRunning.mode`;
  `FlutterErrorListener` (M3) открывает своё соединение по адресу — так же и выбор.
- Снимки приложения уже сохраняются в `.dart_tool/flutter_code_agent/screenshots/`
  (`kScreenshotsFolder`, не больше `kScreenshotLimit = 20`) и уходят в черновик как `@путь`
  (`WorkspaceRunLink.addScreenshot`); черновик выбора — `@widget Имя (файл:строка)`.

## 1. Клиент инспектора и выбор

- `WidgetInspectorClient` (`feature/app_run/data/widget_inspector_client.dart`) — тонкий слой над
  `vm_service`, как `FlutterErrorListener`. `WidgetPickerRepositoryImpl` заменяет фейк за
  `IWidgetPickerRepository`; держит один клиент на запуск проекта: открывается при первом выборе по
  `vmServiceUri`, закрывается при остановке запуска, смене адреса и `dispose` (выход из приложения).
- Группа объектов `flutter_code_agent_picker`; освобождается перед каждым новым выбором.
- Кнопка доступна, только когда запуск `RunRunning` в `BuildMode.debug` с `vmServiceUri`; иначе она
  выключена с причиной: «не запущено», «сборка profile/release», «ждём VM service приложения».
- Выбор:
  1. Найти изолят с `ext.flutter.inspector.show` (на каждом выборе — после hot restart изолят новый);
     подписаться на потоки `ToolEvent` и `Extension` (один раз на соединение).
  2. `show(enabled: true)`; карточка: «Коснитесь виджета в приложении» и «Отмена».
  3. Ждать без лимита: событие `navigate` (`source: flutter.inspector`) → выбор; `show` стал `false`
     (пользователь вышел из режима в приложении), «Отмена», конец запуска, hot restart → отмена.
  4. `getSelectedSummaryWidget` → имя, `creationLocation`, id.
  5. `getParentChain(id)` → виджеты проекта (`createdByLocalProject`) от выбранного к корню, ближний
     первым, не больше 8, у каждого имя, место и id.
  6. `screenshot(id, width: 800, height: 800, maxPixelRatio: 2)`.
  7. `show(enabled: false)` — всегда, и после отмены и ошибки.
- Результат — `PickedWidget`, расширенный: файл относительно проекта (из `file://` URI), `column`,
  `id`, предки как записи `(name, file, line, column, id)`, PNG байтами (`null`, если снимок не вышел).
  `pick` возвращает `PickResult`: выбранный виджет, отмену, «нет виджета проекта», «виджета больше нет» или ошибку (`PickFailure`).

## 2. Что уходит в чат

- Выбор только заполняет карточку; в черновик — по «Добавить в сообщение», ничего не отправляется.
- Текст: `@widget BookingCard (lib/…/booking_card.dart:42:7)` и строка `in: BookingList › BookingScreen`
  (предки после выбранного).
- Снимок: PNG сохраняется в `kScreenshotsFolder` как `widget-<Имя>.png` (с номером при совпадении), в
  общий лимит 20; `@путь` — в черновик после текста; запоминается для меню `@`, как снимки приложения.
- Нет открытого чата — существующее «Сначала откройте чат».
- Касание пришлось только на виджеты фреймворка (нет виджета проекта вокруг) — карточка «Здесь нет
  виджета вашего проекта», «Добавить в сообщение» выключено.

## 3. Цепочка предков

- Карточка показывает цепочку от выбранного виджета наружу; текущий выделен (`context.colors.accent`,
  тонированный фон).
- Клик по звену переключает карточку на этот виджет по его id: имя и место из звена, новый снимок
  (`screenshot(id)`), цепочка заново (`getParentChain(id)`); выделение переходит на звено. Новое
  касание в приложении не нужно, экран приложения не меняется (режим выбора выключен, а с ним и
  рамка — см. факты).
- Id живут до освобождения группы (следующий выбор, остановка или hot restart запуска): клик по
  устаревшей цепочке — «Этого виджета больше нет, выберите снова», карточка оставляет последние данные.

## Ошибки и края

| Случай | Поведение |
| --- | --- |
| Не запущено / profile / release | Кнопка выключена с причиной |
| Запущено, VM service ещё нет | Кнопка выключена: «Ждём VM service приложения» |
| Нет изолята с `ext.flutter.inspector.show` | Выбор падает: «Инспектор виджетов недоступен в этом приложении» |
| Hot restart или остановка во время выбора | Выбор отменён; `show(false)`, если приложение отвечает; карточка возвращается к прежнему содержимому |
| Пользователь вышел из режима в приложении | Как «Отмена» |
| Соединение VM service оборвалось | Выбор падает одной строкой; следующий выбор открывает новое соединение |
| Касание вне виджетов проекта | «Здесь нет виджета вашего проекта» |
| Снимок не вышел (`null`) | Карточка и текст работают, снимка нет, карточка говорит об этом |
| Клик по устаревшей цепочке | «Этого виджета больше нет, выберите снова» |
| Выход из приложения во время выбора | `dispose`: `show(false)`, затем закрыть соединение |

## Тестирование

- Клиент и репозиторий — со сценарным VM service (`test/support/scripted_vm_service.dart` из M3 +
  расширения инспектора и поток `ToolEvent`): весь выбор; summary-виджет, цепочка (≤ 8, ближний
  первым, только `createdByLocalProject`), пути относительно проекта; `show(false)` всегда; устаревший
  id после hot restart; каждая отмена (кнопка, выход из режима, конец запуска, restart); освобождение
  группы перед выбором; `dispose` во время выбора.
- Виджеты: доступность кнопки и причины; карточка — подсказка, результат, выделение звена, клик по
  звену; «Добавить в сообщение» кладёт текст и `@путь`; состояния «нет виджета проекта» и «больше нет».
- Opt-in (`FLUTTER_RUN_TEST=1`, тег `flutter`): `flutter run` маленького приложения на macOS в debug,
  выбор, выделение известного виджета через `setSelectionById` (тест не может коснуться экрана; это
  тоже публикует `navigate`) → имя, файл и строка, цепочка, непустой PNG.
- `FakeWidgetPickerRepositoryImpl` и Preview-пометка выбора удаляются; виджетные тесты берут заглушку
  из `test/support/`.

## Решения M6

- Выбор говорит с инспектором через своё соединение VM service, не через Dart MCP или DTD (выбор
  пользователя: подход A) — работает без чата и любого агента.
- «Список» — цепочка предков проекта в карточке; клик переключает карточку по id, приложение не
  подсвечивает (выключение режима выбора очищает выделение).
- Один выбор, затем режим выключается; в чат — текст и снимок виджета через `@путь`, как снимки
  приложения; ничего не отправляется само.
